## Retained snapshot

The wiki records an exact committed game revision. The marker above is the revision represented by every generated dossier, configuration readout, palette swatch, upgrade listing, and Builder calculation in this retained snapshot. It is a provenance marker, not a live synchronization claim.

## Release boundary

The legacy game-data listener remains disabled while G6 designs the typed game-reference contract. This page therefore does not claim that a game update automatically refreshes or deploys the wiki. The source marker answers only which retained game revision this wiki content describes.

Narrative patch notes belong in the game’s release notes. This reference page deliberately avoids copying balance values, rosters, or version claims that could become stale.
