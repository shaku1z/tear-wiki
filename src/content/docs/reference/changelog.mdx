## Validated reference

The wiki records the exact source commit, validation run, schema, and manifest hash shown above. Modern dossiers, upgrade listings, palettes, and the Builder consume the validated game-reference artifact; the marker is provenance, not a deployment or live synchronization claim.

## Release boundary

Game-reference promotion remains an explicit protected workflow. A source update does not automatically refresh, merge, or deploy the wiki; the marker answers which validated artifact this wiki revision describes.

Narrative patch notes belong in the game’s release notes. This reference page deliberately avoids copying balance values, rosters, or version claims that could become stale.
