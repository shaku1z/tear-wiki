## Compatibility boundary

This page is an explicit compatibility reference, not a current product roster. It does not authorize new public copy to use a deprecated alias. Historical records, imported artifacts, replay metadata, and migration readers retain their original identifiers so they can be read without changing hashes or semantics.

The terminology registry is bound to the validated game-reference artifact identified by the source status above. Historical G4 provenance remains preserved separately; this page does not regenerate or re-vendor game data.
